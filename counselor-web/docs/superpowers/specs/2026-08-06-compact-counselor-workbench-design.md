# 咨询师工作台紧凑待办设计

## 目标

首页只帮助咨询师判断每个案例此刻要做什么，不展示完整流程轨道。

## 展示

- 每个订单只显示一行。
- 信息固定为：头像、姓名、当前节点、说明、完整预约日期与时间、一个操作按钮。
- 当前节点名称为：预约等待确认、前序资料待查阅、即将开始咨询、待确认总结。
- 操作按钮为：确认、查看、进入、确认总结。
- 仅“待确认总结”按需显示结算锁定提示。
- 没有待办时显示“所有业务待办已完成”。

## 不展示

- 首页不显示四步流程轨道。
- 首页不显示已完成勾选、跳过状态或未来节点锁定图标。
- 不使用“复盘”文案。

## 数据与交互

- 保留 `确认预约 → 查阅资料 → 开始咨询 → 确认总结` 的完整底层状态链。
- 工作台继续通过旅程投影为每个订单选出唯一当前任务，避免同一案例重复出现。
- 点击按钮沿用现有动作；完成资料查阅后，当前任务更新为开始咨询。
- 总结提交、IM 卡片、评价与结算联动不变。

## 验收

- 一个案例最多一行、一个按钮。
- 页面不出现四步节点条。
- 四种当前任务都能显示正确文案并执行原有动作。
- 移动端不横向溢出，日期和时间允许合理截断但保留完整值供无障碍读取。
