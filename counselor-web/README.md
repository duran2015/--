# 可鹿心理双端业务原型

本仓库是可鹿心理平台的完整双端演示版，包含：

- `src/`：React + Material 3 咨询师工作台。
- `flutter-client/`：Flutter + Material 3 用户端。
- `src/client-app/`：早期 React 用户端原型，作为视觉和业务参考保留。

当前版本以“前端可演示的完整业务闭环 + Mock 状态流转”为目标。真实支付、数据库、音视频、IM、AI 转录和情绪识别接口由后续 Builder 按文档接入。

## 本地运行

### 咨询师端

```bash
npm install
npm run dev
```

默认访问：`http://localhost:4311/counselor`

### 用户端

```bash
cd flutter-client
flutter pub get
flutter run -d web-server \
  --web-hostname 0.0.0.0 \
  --web-port 4312 \
  --dart-define=API_ENV=mock \
  --dart-define=DEV_AUTO_LOGIN=1
```

默认访问：`http://localhost:4312/splash#/home`

## 对比原 Flutter 双端版本的功能调整

### 1. 统一账号与双身份

- 首次注册默认进入用户端，不强制普通用户选择身份。
- 登录页保留“我是咨询师”入口；未入驻账号进入资质申请流程。
- 已具备双身份的账号记录最近使用身份，并可在“我的”中切换用户端/咨询师端。
- 账号主体、用户资料、咨询师资料和最近身份分开保存。

### 2. 预约、订单与工作流分层

- 咨询师端工作台按单个案例展示当前事项，不再展开臃长的全链路节点。
- 用户端和咨询师端统一订单卡片、状态徽标、头像、SKU、预约时间和操作规则。
- 订单状态只表达交易/履约：待支付、待咨询师确认、待咨询、咨询中、已完成、已取消、已退款。
- 填写前序资料、等待回顾、查看回顾、评价等被定义为工作流事项，不再伪装成订单状态。
- Mock 数据覆盖支付、咨询师确认、前序资料、咨询室、等待回顾、查看回顾和评价。

### 3. 预约规则、取消与改期

- 用户下单和订单详情统一展示咨询师可服务时间、SKU、最小预约时长、取消和退款规则。
- 取消规则明确区分 24 小时以上、不足 24 小时和服务开始后。
- 改期改为两阶段流程：用户先在订单底部提交原因 → 咨询师同意 → 用户再从排期控件选择新时间。
- 咨询师确认改期前，原预约仍然有效。

### 4. IM 消息与业务卡片

- 双端统一会话头像、消息气泡、输入栏和业务卡片规则。
- 消息分为安全强提醒、状态通知、SOP 动作卡和普通对话气泡。
- SOP 卡片属于订单/会话公共状态，居中展示，字段和操作按钮按角色投影。
- 预约申请、确认预约、填写资料、进入咨询室、回顾确认/分享和双方评价均可生成 IM 卡片或状态通知。
- 用户图片消息增加显示尺寸限制，避免大图撑满会话。
- 安全提醒、订单卡和操作按钮按 Material 3 视觉层级收紧。

### 5. 咨询室与 AI 辅助

- 语音和视频咨询室双端使用一致的会议信息、头像、时长、网络状态和底部控制舱。
- 用户端只显示与自己相关的音视频操作；咨询师端额外显示转录、AI 重点、咨询笔记和风险上报。
- 语音通话支持持续接收语音情绪识别结果；视频通话支持多模态情绪识别结果。
- 情绪数据按“接口结果 + 置信度 + 时间”展示，前端不自行诊断用户情绪。
- 咨询结束后不再直接跳首页，而是进入转录、AI 重点、咨询师记录和回顾确认页。

### 6. 咨询回顾、作业与结算

- 咨询师可结合实时转录、AI 重点、私密笔记和本次观察编辑回顾。
- 回顾包含寄语/小结、推荐会后行动和下次探讨方向。
- 咨询师确认后向用户分享，同时向 IM 和待办投递回顾卡片。
- 用户查看回顾后可评价；咨询师结算与回顾完成联动。
- 不再使用“复盘”作为用户服务节点，统一使用“确认总结/咨询回顾”。

### 7. 用户信息、咨询匹配与隐私

- 用户可编辑头像、昵称、个人签名、性别、年龄段、城市和职业/生活阶段。
- 用户资料按用途拆成“基础资料、咨询偏好、支持档案”，避免把敏感信息混在公开个人页。
- 支持档案默认仅自己可见；用户授权后才向本次咨询师提供快照。
- 引导触发点包含首次进入、浏览咨询师、预约完成、开始前 24 小时、咨询结束和 3 个月未维护。
- 基础量表和前序资料采用可选、可跳过和明确用途的方式，不在新用户登录时强制答题。

### 8. 咨询师私域经营与工作台

- 咨询师可通过分享入口承接自有用户预约，也可录入线下案例进行统一管理。
- 私域订单在统一界面管理，当前产品定义为不额外抽佣；支付通道费按实际发生处理。
- 用户授权后可用于服务跟进和合理频率的营销触达；用户可关闭营销类通知。
- 工作台包含待办、预约、订单、收入、服务 SKU、排班、预约规则、资质和用户档案。

### 9. 咨询师入驻、资质与头像审核

- 补充咨询师入驻、资质提交和审核状态。
- 增加平台入驻协议入口，支持待签约、签约中、已签约和签字结果展示。
- 咨询师个人主页、资质、受训、咨询取向、擅长领域、服务方式和简介可编辑。
- 咨询师头像更换需平台审核，状态包含已通过、审核中和未通过。
- 审核期间继续展示已通过的旧头像；驳回时展示原因并允许重新上传。

### 10. 系统通知与账号管理

- 用户端和咨询师端都提供独立系统通知会话。
- 通知类型包括订单/行程动态、平台活动、优惠信息、账户与安全、服务跟进和 AI 助手。
- 通知类型、图标、文案和跳转目标可由运营后台配置；客户端使用 Mock 数据演示。
- 用户可主动关闭非必要通知，订单履约、账户安全和必要合规通知保留。
- 双端统一补充关于我们、意见反馈、账号与安全、切换身份、退出登录和注销账号。

## Builder 对接边界

当前以 Mock 投影完成业务走查，Builder 接入时需实现：

- 统一账号与双身份权限。
- 咨询师、SKU、排期、预约规则、订单、支付、取消、退款、改期和结算。
- IM 普通消息、系统通知、SOP 卡片和待办投递。
- 音视频房间、实时转录、语音/多模态情绪识别、AI 重点和风险事件。
- 用户资料授权快照、咨询师私密记录、咨询回顾、作业、评价和结算联动。
- 咨询师资质、头像、平台协议和签约审核。
- 通知模板、类型、频率、开关和营销授权管理。

详细后端建议与状态契约参考 `docs/`。
